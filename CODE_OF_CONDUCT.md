# Code of Conduct

This project adopts the **Contributor Covenant, version 2.1**, as its code of conduct:
<https://www.contributor-covenant.org/version/2/1/code_of_conduct/>

All contributors, maintainers and participants in project spaces (issues, pull requests, discussions,
and any other channel used for the project) are expected to follow it.

## Reporting

Report unacceptable behaviour to the project maintainer, Kaveeshan Thurairajah, at
**kavee@thurairajah.org**. All reports will be reviewed and investigated promptly and fairly, and the
privacy and security of the reporter will be respected.

Enforcement follows the Community Impact Guidelines of the Contributor Covenant 2.1 (correction, warning,
temporary ban, permanent ban).
